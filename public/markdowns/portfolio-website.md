# Portfolio Website

## Overview

Personal portfolio that showcases projects, technical skills, and a modern web design built with React and Material UI.

**Live Site:** https://nicksportfolio.tech/
**Repository:** https://github.com/firepenguindisopanda/react-portfolio-website

---

## Tech Stack

- React (frontend)
- Material UI, Framer Motion for animation
- Firebase for hosting and optional features

---

## Key Features

- Home page with sections for experience, projects, and contact
- Project cards with detailed markdown writeups and interactive UI
- Themed layout with dark/light toggle and smooth transitions

---

## Local Setup

- Install dependencies via `npm install` and run `npm run dev` to preview locally

---

This site was built as a personal showcase and is continually updated with new projects.
